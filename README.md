# Circuit Lab — EM-PLAYGROUND

전기공학 학습을 위한 로컬 회로 편집·수치 해석 웹 앱입니다. R/L/C와 독립·종속 전원, 다이오드, 두 OP AMP 모델, 전류 센서, DC 포트 분석, transient/AC 파형과 페이저 학습을 하나의 브라우저 작업 공간에서 다룹니다.

이 폴더는 CIRCUIT-024를 부모로 만든 **EM-PLAYGROUND 최신 실행본**입니다. 기존 회로 기능과 전자기학 3D 작업공간에 자유실험실 A–D 구현을 포함합니다. 현재 인계 상태는 저장소 루트의 [2026-10-02 인계 문서](../../../deliverables/Circuit-Lab-Agent-Handoff-2026-10-02.md)를 참조하십시오.

처음 실행한다면 [START-HERE.md](START-HERE.md)를 먼저 읽으십시오.

## 실행

Node.js 20 이상이 필요합니다. 022 검증 환경은 Windows / Node.js 24.21.0입니다.

```powershell
# 저장소 루트에서
Set-Location .\candidates\EM-PLAYGROUND\source
node .\server.mjs 4173
```

`http://127.0.0.1:4173/`을 열고 서버 터미널의 `Ctrl+C`로 종료합니다. 포트가 사용 중이면 `node .\server.mjs 4197`처럼 바꿉니다.

런타임 외부 패키지·계정·CDN·인터넷은 필요하지 않습니다. 서버는 `index.html`, `styles.css`, `src/*.js`만 localhost에 제공하며 CSP와 허용 경로를 유지합니다. `file://` 직접 실행은 사용하지 마십시오.

보조 실행기는 다음과 같습니다. 022 실제 UI 근거는 `server.mjs` 직접 실행으로 수집했으므로 보조 실행기 자체를 검증 완료로 확대하지 않습니다.

```powershell
node .\scripts\launch.mjs 4173
node .\scripts\launch.mjs 4173 --no-browser
# 또는 Windows에서 start-circuit-lab.cmd
```

## 현재 작업 공간

상단 `회로`와 `전자기학 3D` 탭으로 작업공간을 바꿉니다. 탭 전환은 회로 입력 draft·선택·history·probe·port·결과·Worker를 저장하거나 취소하지 않습니다. 전환 순간 진행 중인 포인터 조작만 비확정 취소합니다.

| 영역 | 기능 |
|---|---|
| 편집 도구 | 선택·이동, 다중 꺾임 배선, V/I 프로브, 화면 이동, undo/redo, 복제, 회전, 삭제 (글자 라벨 버튼) |
| 고정 배치 | 왼쪽 부품(기본 부품, 종속원·센서는 더보기), 가운데 캔버스, 오른쪽 속성/결과 탭, 아래 파형 |
| 캔버스 | 격자·snap, 명시적 접속점과 단순 교차 구분, 확대·이동·화면맞춤, 회로 상태 색·설명 |
| 분석 | 선택 한 곳(자동·DC·시간응답·AC)과 해석 설정(선택한 종류의 값만), Worker 실행·취소, stale/오류 상태 분리 |

배치는 고정입니다(패널 이동·크기 조절·저장 없음). 900px 미만에서는 캔버스 아래에 패널 하나만 보이며 하단 탭 `부품/속성/결과/파형`으로 바꿉니다.

캔버스의 `조작 도움말`은 실제 코드에 등록된 마우스·터치·키보드 동작을 요약합니다. 390×844에서는 좌우 넘침 없이 도움말 내부가 세로 스크롤됩니다.

## 전자기학 3D

- 점전하, 유한 간격의 정확한 두 점전하 쌍극자, 무한 직선전류, 원형 전류고리, 진공 선형편광 평면파를 SI float64로 계산합니다.
- 측정점 xyz와 xy/xz/yz 단면을 함께 쓰며 벡터 성분·크기·전위를 같은 snapshot에서 표시합니다. 고리 측정은 midpoint N=64…1024 수렴 상태와 차이를 함께 보입니다.
- 3D는 외부 vendor 없는 native WebGL입니다. 끌기/화살표키로 orbit, 휠/두 손가락 또는 `+`/`-`로 zoom, 축 버튼과 `Home`으로 시점을 바꿉니다.
- 파동은 기본 정지입니다. 재생·정지·단계·0…2T 시간·표시 속도를 제공하며 탭 이탈, 문서 숨김, 창 blur 뒤 자동 재생하지 않습니다.
- 점전하·직선축 1 mm와 고리 `max(1 mm, 0.02R)` 안쪽은 모델 제외영역입니다. 화살표 길이·단면 색·장선은 보기용 정규화이며 물리 세기나 오차 한계가 아닙니다.
- `c=299792458 m/s`는 정확값, `μ₀=1.25663706127e−6 H/m`는 CODATA 2022 측정값이며 ε₀와 Coulomb 상수는 둘에서 파생합니다. 재료·경계조건·유도전류·방사 근접장·회로 결합은 범위 밖입니다.

## 편집 조작

### 마우스·키보드

- 부품을 골라 캔버스에 연속 배치하고 `Esc`로 종료합니다.
- 배선 도구에서 핀·접속점을 시작점으로 누릅니다. 빈 격자점은 고정 waypoint, 다른 핀·배선·접속점은 끝점입니다.
- 항목 클릭은 선택, 선택 항목 끌기는 이동, 빈 캔버스 끌기는 화면 이동, 휠은 확대·축소입니다.
- `R` 회전, `Delete` 삭제, `Ctrl/Cmd+D` 복제, `Ctrl/Cmd+Z` undo, `Ctrl/Cmd+Y` 또는 `Shift+Cmd+Z` redo입니다.
- 값 글자 더블클릭은 inline 편집입니다. `Enter`로 적용하고 `Esc`로 취소합니다. 입력 중 회로 단축키는 비활성입니다.
- 전압 프로브는 핀·배선·접속점, 전류 프로브는 부품에 추가합니다. 우클릭 메뉴나 목록의 제거 버튼은 해당 프로브만 지웁니다.

### 터치·좁은 화면

- 먼저 탭해 선택한 부품 또는 접속점만 다음 끌기에서 이동합니다.
- 그 밖의 한 손가락 끌기는 화면 이동, 두 손가락은 확대·축소입니다.
- 배선·프로브는 먼저 도구를 선택한 뒤 대상점을 탭합니다.
- 패널은 캔버스 아래에 하나만 보이고 하단 탭으로 전환합니다. 부품을 고르면 캔버스로 되돌아갑니다.
- 44px 조작 대상과 글자 라벨 도구 버튼을 사용합니다. 작은 SVG 삭제 버튼은 coarse pointer에서 숨깁니다.

390px 브라우저 경로와 pointer 관련 회귀는 확인했지만 물리 iPhone/Safari 손가락 이벤트·가상 키보드는 미확인입니다.

## 지원 소자와 해석

지원 소자는 다음과 같습니다.

- R, C, L, GND
- 독립 전압원·전류원: DC, SIN, PULSE, AC
- 간략 Shockley 다이오드
- 유한 이득 `OPAMP`, 이상 제약 `OPAMP_IDEAL`
- 전압 제어 전압원/전류원 `VCVS`, `VCCS`
- 0 V 전류 센서 `CURRENT_SENSOR`, 전류 제어 전류원/전압원 `CCCS`, `CCVS`

해석 의미:

- DC: C 개방, L 단락의 동작점
- transient: 고정 간격 backward Euler, 마지막 구간은 실제 남은 시간
- AC: DC 동작점 주위 소신호, 입력은 peak/cos 페이저
- transient SIN: sin 기준이며 AC 위상과 몰래 일치시키지 않음

Worker가 분석을 수행하며 새 분석·입력 변경·사용자 취소 시 이전 작업을 terminate하고 generation으로 stale 결과를 차단합니다. 계산 취소와 표시 stale은 서로 구분됩니다.

## 수치·표시 계약

- 전압과 전류는 서로 다른 Y축입니다. 같은 물리량의 여러 trace는 공통 V/mV/µV 또는 A/mA/µA 배율을 씁니다.
- DC는 가짜 시간 표본 없이 한 동작점으로 표시합니다.
- AC 그래프는 dBV/dBA 절대 레벨 또는 위상을 표시합니다. 0 진폭은 로그 크기 `-Infinity`, 위상 미정입니다.
- 전류의 양수 기준은 일반 2핀 소자의 pin 1→2입니다. 종속원·센서는 p→n, OP AMP는 출력→내부 기준이며 회전된 실제 핀에 화살표가 맞춰집니다.
- 다이오드는 Is/n 기반 간략 모델이며 제조사 정밀 모델·역방향 breakdown이 아닙니다. Newton 안정화와 표시 전류는 같은 원 모델을 사용합니다.
- 간략 OP AMP는 유한 개방루프 이득이며 rail·포화·GBW·slew rate가 없습니다. 이상 OP AMP는 `V+=V−` MNA 제약이며 안정성을 판정하지 않습니다.
- `E/e`, `µ/μ/u` 접두사를 지원하고 M/m/F/f 의미를 구분합니다. 물리 단위 차원 검사까지 제공하지는 않습니다.
- 편집 상한은 부품 256, 배선 2048, 접속점 1024, 동시 미지수 128입니다. 표본 최대 20001과 계산량 예산도 검사합니다.

## DC 포트와 페이저

테브난·노턴 패널에서 실제 핀 또는 명시적 접속점으로 p/n 포트를 고르고, 선택한 저항성 부하를 포함하거나 제외할 수 있습니다. 결과는 `Vth`, `Rth`, `In`과 전압·전류 방향, 특이형이면 구체 사유를 표시합니다. 현재 범위는 DC 선형 포트이며 AC/소신호 포트가 아닙니다.

페이저 패널은 같은 AC 해석 결과의 복소평면, 직교형·극형, 대응 정현파, RLC 임피던스를 보여줍니다. 별도 연습 탭의 복소수 입력은 실제 회로·저장 JSON·해석 결과를 바꾸지 않습니다.

## 프로젝트 JSON과 CSV

- `저장`은 회로, 분석 설정, 프로브를 `circuit-lab` JSON으로 내보냅니다. 현재 센서/CCCS/CCVS가 있으면 version 3을 사용합니다.
- `열기`는 작성 중 회로의 구조와 해석 가능성을 분리해 읽으며, 잘못된 설정·probe 참조·중복 ID·안전하지 않은 색을 거부합니다.
- 테마는 표시 설정이며 회로 JSON과 분리됩니다. 패널 배치는 저장하지 않습니다.
- DC/transient CSV 수치는 원시 V/A, 시간은 s입니다. AC는 dBV/dBA와 phase degree입니다.
- CSV 헤더는 쉼표·따옴표·줄바꿈을 escape하고 스프레드시트 수식 문자로 시작하면 작은따옴표를 붙입니다. 수치 표본은 변경하지 않습니다.

022에서는 실제 파일 선택기로 `mixed-probe-units.json`을 다시 열어 제목·4개 부품·3개 probe와 DC `10 V`, `10 mA`, `10 µA`를 확인했습니다. 시험 브라우저가 Blob 다운로드 이벤트를 노출하지 않아 저장 다운로드 파일 자체는 `INCONCLUSIVE`입니다.

## 검증

- `tests/engine/` — 회로 엔진·포트·전자기·신호·회로 과정 계산(수치·기호). 독립 기대값과 `tests/fixtures/`를 씁니다.

npm run test:summary   # npm test와 같은 범위, 원시 TAP를 .verification/ 또는 --out 폴더에 보존

## 범위와 남은 제한

- 최신 EM A–D는 2026-10-02 인계에서 운영 수용 완료로 기록됐습니다. 문서의 022 검증과 023 기능 설명은 이전 후보의 근거·제한이며, 최신 EM 관련 결과와 미관측 범위는 위 인계 문서를 참조하십시오.
- 부모의 7실패 중 ideal OP AMP와 중복 capacitor 진단 우선순위 충돌은 solver 계약 판단이 필요한 고위험 항목으로 분리돼 있습니다.
- 실제 손가락 touch, Safari/WebKit, 모든 극단 viewport, 저장·CSV 다운로드 파일, 공개 배포는 022에서 확인하지 않았습니다.
- 실제형 OP AMP, AC/소신호 포트, 재료를 포함한 FEM/Maxwell 해석은 023 기능이 아닙니다.
- 오실로스코프형 화면은 실제 계측기의 trigger·sampling·bandwidth 모델을 흉내 내지 않습니다.

설계·수치 계약은 [docs/COMMON-CONTRACTS.md](docs/COMMON-CONTRACTS.md), 상세 실행 결과와 7실패 분류는 저장소 루트의 `results/CIRCUIT-022/`를 참조하십시오.
