# Circuit Lab

전기공학 학부 학습용 로컬 웹 앱입니다. 브라우저에서 회로를 그려 DC·시간응답·AC를 수치 해석하고, 파형을 측정하며, 같은 화면 틀의 학습 작업공간 셋(전자기학 · 신호 및 시스템 · 회로 과정(AC·3상))을 쓸 수 있습니다. 학습 화면은 슬라이더를 움직이면 그림이 바로 바뀌는 방식입니다. 빌드 단계와 외부 패키지·CDN·계정이 없고, 회로 해석은 브라우저 안(Web Worker)에서만 계산합니다.

학습 작업공간은 수업 진도에 맞춰 만들었습니다: 회로 과정은 전기회로2 Ch.9–13(복소수·페이저, 복소전력·최대전력전달, 3상, 결합 인덕터·변압기), 신호 및 시스템은 Ch.01·02·04(신호·LTI 응답·푸리에), 전자기학 문제 풀이는 Hayt Ch.8(자기력·자성체·자기회로·인덕턴스)입니다. 강의 슬라이드의 문장·그림은 옮기지 않았고, 예제 번호와 교재 수치(허용 오차 안)만 대조 기준으로 둡니다.

처음 작업하는 개발자는 [START-HERE.md](START-HERE.md), 구조는 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), 화면 설계 원칙은 [DESIGN.md](DESIGN.md)를 보십시오.

## 실행

Node.js 20 이상이 필요합니다(시험은 22 이상).

```powershell
.\start-circuit-lab.cmd          # Windows: 서버 시작 + 기본 브라우저 열기 (포트 4173)
node server.mjs 4173             # 서버만 시작. 포트 0이면 빈 포트를 자동 선택
node scripts\launch.mjs 4191     # 다른 포트로 시작 + 브라우저 열기 (--no-browser 가능)
```

브라우저에서 `http://127.0.0.1:<포트>/`를 열고 서버 콘솔에서 `Ctrl+C`로 끝냅니다. `file://` 직접 열기는 지원하지 않습니다. 서버는 `127.0.0.1`/`localhost` 요청만 받고 `index.html`, `styles.css`, `src/*.js`만 제공합니다(CSP·`no-store` 포함).

시작 주소 매개변수: `?example=<id>`(예제 열기), `?run=1`(시작 시 해석), `?workspace=em|signals|circuit-course`(시작 탭), `#p=…`(공유 링크).

## 기능

### 편집기 조작
- 소자: R, C, L, GND, 독립 전압원·전류원(DC·SIN·PULSE·AC), 간략 다이오드, 간략 OP AMP(유한 이득)·이상 OP AMP, 그리고 `더보기`의 VCVS·VCCS·0 V 전류 센서·CCCS·CCVS, 자기결합 부품인 **결합 인덕터(K)**와 **이상 변압기(T)**.
- **결합 인덕터·이상 변압기**(교재 Ch.13): 4핀(1a·1b 1차, 2a·2b 2차), 점은 1a와 2a(`점 위치`를 반대로 하면 2a 대신 2b). 결합 인덕터는 L1·L2와 결합계수 k 또는 상호 인덕턴스 M(둘 중 하나를 입력하고 다른 하나는 유도값으로 표시)을 가지며 v1=L1·di1/dt+M·di2/dt, v2=M·di1/dt+L2·di2/dt입니다(i1, i2는 점 핀으로 들어가는 방향이 양수). DC에서는 두 권선이 모두 단락이고 AC는 jωL1·jωL2·jωM이며, 0≤k≤1(M≤√(L1L2))입니다. k=1은 부하가 있을 때만 풀립니다. 이상 변압기는 권수비 n=N2/N1(>0)로 v2=±n·v1, i1=∓n·i2(V1·V2 점 극성이 같으면 +n, I1·I2 모두 점으로 들어가면 −n)이고 S1=S2이며 DC·시간응답·AC가 모두 같습니다. 1차와 2차는 서로 절연이라 **2차 회로에도 GND**가 있어야 합니다. 전류 프로브는 I 프로브 도구로 부품의 왼쪽 절반(I(K1.1))·오른쪽 절반(I(K1.2))을 눌러 권선별로 답니다. 예제: `결합 코일 (예제 13.1)`, `이상 변압기 (예제 13.8)`.
- 부품을 골라 연속 배치(`Esc` 종료). 배선은 핀에서 다른 핀·배선·접속점까지 **끌거나**(선택·배선 도구 모두), 핀을 차례로 눌러 꺾임 배선(빈 격자점 = 꺾임). 끌다가 빈 곳에 놓으면 배선이 그대로 이어져 계속 그릴 수 있고 `Esc`로 취소합니다. 배선을 두 번 누르면 접속점이 생기고, 단순 교차는 접속이 아닙니다.
- 끌어서 이동, 회전, 복제, 삭제, 복사·잘라내기·붙여넣기, 되돌리기/다시 하기(100단계), 확대·축소·화면 맞춤·화면 이동.
- **다중 선택**: `Shift`+클릭으로 부품·배선·접속점을 선택에 더하거나 뺍니다. `Shift`+빈 곳 끌기는 상자 선택(부품은 상자에 닿으면, 배선은 경로 전체가 상자 안일 때 포함, 기존 선택에 더함)이며 빈 곳 일반 끌기는 그대로 화면 이동입니다(터치에는 상자 선택이 없음). 선택된 부품 하나를 끌면 선택 전체가 함께 움직이고, 삭제·복제·회전·방향키 이동·붙여넣기는 각각 실행 취소 한 단계입니다. 둘 이상 선택하면 속성 칸에 `N개 선택`과 복제·회전·삭제만 나옵니다. 그룹 회전은 마지막으로 누른 부품을 축으로 돕니다(기본 항목이 배선이면 마지막으로 고른 부품). 붙여넣기는 복사한 부품 사이의 배선·제어원 참조를 새 ID로 옮기고, 붙여넣을 때마다 2칸(40) 비껴 놓입니다. 복사한 부품의 참조 라벨은 겹치면 다음 빈 라벨(R3…)로 바뀝니다. 복사는 시스템 클립보드에 JSON을 남기고, 붙여넣기는 브라우저의 붙여넣기 이벤트로 최신 시스템 클립보드의 Circuit Lab JSON을 우선 읽습니다(없으면 앱 안 클립보드). 다른 회로에서 붙이면 조각 밖 제어 대상을 지우고 다시 고르게 합니다. 글자 칸에 있거나 글자를 드래그해 선택한 상태에서는 복사·모두 선택이 브라우저 기본 동작입니다.
- **Y–Δ 변환**: 저항 정확히 3개를 선택하면(`Shift`+클릭) 속성 칸의 다중 선택 패널에 `Y→Δ 변환` 또는 `Δ→Y 변환` 단추가 뜹니다(한 점에서 만나는 Y, 또는 삼각형 Δ로 인식될 때. 아니면 이유를 title·본문에 적은 비활성 단추). 단축키는 `Y`. 이력 한 단계이고 선택은 새 저항 3개로 옮겨 가며, 코너 노드에 붙은 다른 부품·프로브는 그대로 이어집니다(중심 노드에 다른 부품이 있는 별은 거부). 새 값은 로그 영역 계산이라 노드 전압·전원 전류가 변환 전과 같습니다. 예제 `Y 저항망 (Y–Δ 변환)`으로 해 보세요.
- 값 글자 더블클릭 = 화면에서 바로 편집(`Enter` 적용, `Esc` 취소). R·C·L 값 글자 위에서 휠 = E12 표준값 한 칸.
- V 프로브(핀·배선·접속점)와 I 프로브(부품). 프로브가 걸린 대상을 우클릭하면 그 프로브만 제거하는 메뉴가 뜹니다.
- 해석 후 핀·배선·접속점·부품에 마우스를 올리면(터치는 탭) 전압·전류·전력 판독값이 뜹니다.
- `전류 흐름`(해석 줄의 체크박스, 기본 꺼짐·브라우저에 기억): 배선 위에 전류 방향과 크기를 움직이는 점으로 보여 줍니다. DC는 동작점, 시간응답은 그래프 커서 시점(없으면 마지막 표본)이며 속도는 실행 중 최대 전류 대비 4단계입니다. 같은 넷 안에서 배선이 고리를 이루면 그 구간의 전류 분배는 정해지지 않아 점을 그리지 않고, AC는 `페이저로 확인하세요` 안내만 나옵니다. 오래된 결과에는 그리지 않으며 부품을 끌어 옮기는 동안 숨깁니다. 모션 줄이기 설정에서는 움직임 대신 배선마다 정지 화살표 하나를 보입니다.
- 레이아웃은 고정입니다. 데스크톱은 왼쪽 부품 / 가운데 캔버스 / 오른쪽 속성·결과 / 아래 파형이고, `파형 크게`로 캔버스와 파형의 높이 비율을 바꿉니다. 900px 미만에서는 캔버스 아래에 패널 하나만 보이며 하단 탭 `부품/속성/결과/파형`으로 바꿉니다.
- 입력 중인 값(draft)은 해석·저장·되돌리기·파일 열기 때 확정하거나 `입력 취소`로 버립니다. 작업공간 탭을 옮겨도 확정하지도 버리지도 않습니다.

### 해석
- 해석 종류: 자동 / DC / 시간응답 / AC. `자동 갱신`이 켜져 있으면 편집 250 ms 뒤 다시 계산하고, 연결이 끝나지 않았거나 입력 중이면 기다립니다. `Ctrl+Enter` 또는 `해석 실행`으로 직접 실행, `계산 취소`로 중단.
- DC: C 개방·L 단락의 동작점. 시간응답: 고정 간격 backward Euler(선형 회로는 LU 인수 재사용, 다이오드는 Newton). AC: DC 동작점 주위 소신호, 페이저는 peak·cos 기준. 결과 패널 머리의 **표시 기준 `peak` / `rms`**(단위 칸에는 `V (peak)` / `V (rms)`로 표기)는 표시만 바꿉니다: 입력·저장·계산은 항상 peak이고, rms 표시는 크기를 ÷√2(위상·평균전력 숫자는 그대로, 시간 파형은 순간값이라 그대로)로 보입니다. 적용되는 곳은 페이저 패널(복소평면·값·단위 `V (rms)`), 호버 판독(그래프 커서가 가리키는 표본의 값 포함; 크기·dB 수준, 평균전력 식 라벨 `Re(V_rms·I_rms*)`), CSV 내보내기(머리글 `_pk`/`_rms`, 크기는 선택 기준의 dB)이며, AC 전원 입력 칸은 항상 peak 값 그대로이고 그 아래 줄이 표시 기준 값(예: `V (rms) = 120`)을 보여 줍니다. AC 스윕 그래프의 dB 축(축 제목 `전압 레벨 (peak)`)·그래프 커서 라벨·파형 요약은 peak 기준 그대로입니다. 교재(rms) 예제 13.1·13.8은 전원을 rms×√2(peak)로 넣고 rms 표시로 열려 교재 숫자(I1 11.09 A, 부하 615.4 W 등)가 그대로 보입니다. 프로젝트 파일 형식은 바뀌지 않으며 표시 기준은 저장되지 않습니다.
- 회로나 설정이 바뀌면 이전 결과는 `오래된 결과`로 표시됩니다. 실패하면 오류 코드·확신도·관련 부품 버튼이 있는 진단이 뜹니다.
- 결과 탭: 페이저(복소평면, 대응 정현파, R·L·C 임피던스, 두 신호 위상차, 복소수 연습)와 DC 테브난·노턴 포트(p/n 핀·부하 제외 선택).
- 파라미터 스윕: R·C·L(·OP AMP 이득)을 선택하면 속성의 `스윕`에서 시작·끝·점 수(2~10)·로그/선형을 정해 한 프로브 파형을 겹쳐 그립니다. 60초 안전 한도가 있고, 편집·취소·새 해석이 오면 겹침을 버립니다.
- 한도: 부품 256, 배선 2048, 접속점 1024, 동시 미지수 128, 표본 20001.

### 파형 측정
- 전압·전류는 서로 다른 Y축을 쓰고, 같은 물리량은 공통 V/mV/µV, A/mA/µA 배율을 씁니다. AC는 `크기 (dB)`/`위상 (°)` 전환.
- 눈금 `−`/`+`·휠로 칸당 값 조절, `축 자동`, 끌어서 시간·주파수축 이동.
- 커서 A(클릭으로 고정)와 커서 B(`B 커서` 버튼 후 클릭 또는 Shift+클릭): 원 표본 기준 차이 ΔT·ΔV·1/ΔT·기울기(AC는 Δf·Δ레벨/Δ위상·dB/dec 또는 °/dec).
- 자동 측정 요약(최대 3개 트레이스): 시간응답 Vpp·평균·RMS·주기·주파수, AC 최대 이득·−3 dB 주파수. 표본 사이는 선형(−3 dB는 log f) 보간이며 사유는 말풍선으로 보입니다.
- CSV 내보내기: 원시 SI 표본(AC는 dB와 도). 최신 성공 결과일 때만 활성화됩니다.

### 학습 작업공간
상단 탭은 `회로 / 전자기학 / 신호 및 시스템 / 회로 과정` 네 개입니다. 전자기학·신호·회로 과정은 필요할 때 처음 불러오고(지연 로딩), 회로 편집 상태와 서로 섞이지 않으며, 탭을 떠나면 재생·애니메이션이 멈춥니다. 세 학습 화면 모두 **슬라이더·입력 칸이 즉시 반영**됩니다(`적용`·`계산` 단추 없음. 예외는 회로 과정의 `내 문제`뿐이며 `문제 풀기` 단추가 있습니다). 잘못된 입력은 이유를 알리고 마지막 유효 상태를 유지합니다.

**전자기학** — 위쪽 `평면 / 3D / 문제 풀이` 세 보기:
- **평면**(기본): 위에서 본 2D 샌드박스. `+q`·`−q`·`무한선`·`유한선`으로 전하를 놓고(최대 16개, 비어 있는 자리에 놓임) **끌어서 옮기면** 전위 색·등전위선(`등전위선`)·장선(`장선`, 화살표)·벡터 화살표가 실시간으로 바뀝니다. 전하를 끄는 동안은 거친 초안 격자로, 놓으면 정밀 격자로 다시 그립니다(시험전하·가우스 면을 끄는 동안은 배경을 다시 그리지 않음). 노란 **시험전하**를 끌면 그 점의 E·V가 라벨과 오른쪽 `측정값`에 나옵니다. `가우스 면`을 켜면 구의 단면(원)이 생기고, 끌어 옮기거나 가장자리·손잡이를 끌어 키우며(슬라이더도 있음) `Φ = Q/ε₀`와 수치 ∮E·dA를 비교해 `근사 → 정밀 · 수렴`(또는 `미수렴`, `경계 근처 · 미수렴`)으로 보여 줍니다. 선전하가 면을 가로지르거나 점전하가 면 위에 있으면 적분하지 않고 이유를 알립니다. 전하를 누르면 인스펙터에서 세기(로그 눈금 슬라이더 + 직접 입력)·위치를 바꾸고 복제·삭제·`계산에 포함`을 정합니다. `되돌리기`/`다시`는 끌기 한 번·같은 전하의 연속 편집·추가/삭제/초기화를 한 단계로 셉니다(시험전하 이동은 이력에 넣지 않음). 휠은 확대·축소입니다.
- **자기 모드**: 평면 위쪽의 `전기 | 자기` 스위치(자유 배치 화면에서만)로 같은 평면을 정자계 샌드박스로 바꿉니다. 전류는 도선이 지면에 수직이라 단면에서 점으로 그리며 **⊙ = 전류가 화면 밖으로, ⊗ = 화면 안으로**입니다. `⊙ 전류`·`⊗ 전류`(무한 도선), `루프`(원형 전류 고리), `면전류 K`(무한 판), `유한선`(유한 직선 도선)을 놓고 끌어 옮기면 자기장선(`자기장선`)·|B| 색·B 화살표가 실시간으로 바뀝니다. 노란 측정점은 그 점의 B와 H를 칩 없이 함께 읽어 주고(`H 표시` 칩은 없앴습니다), `암페어 루프`(원/사각형, 반시계/시계, 크기 슬라이더)는 경로 안쪽 전류 I내부와 수치 ∮H·dl을 비교해(판독은 `I내부 = ∮H·dl = +10 A (…)` 한 줄에 이어 수치·∮B·dl 줄, 대칭일 때 H 줄을 더해 짧게 보입니다) `암페어 법칙과 일치`·`근사 중`·`미수렴`으로 알립니다(장면에 유한선이 있으면 닫힌 전류 경로가 아니어서, 경로가 면전류 판·같은 평면의 루프와 만나거나 전류 위에 놓이면 H가 정의되지 않아서 비교하지 않고 이유를 적습니다). `힘` 칩을 켜면 선택한 원천이 다른 원천의 장에서 받는 힘(도선 F/ℓ [N/m], 면전류 [N/m²], 루프·유한선 합력)이 나옵니다. 예제 4개: `평행 도선 쌍`(I₁=I₂=10 A, d=0.2 m → F/ℓ = μ₀I₁I₂/(2πd) = 1.0e-4 N/m, 같은 방향이면 끌어당김) · `한 도선 + 암페어 루프`(경로를 도선에서 비켜 놓아도 ∮H·dl = +10 A) · `면전류 두 장`(사이 B = μ₀K, 바깥 0) · `직선전류 + 루프`. 자기 모드는 3D 탭이 없고, `되돌리기`·`다시 하기` 이력이 전기 모드와 따로입니다. EM 파일(version 2)은 전기 전하에 더해 자기 원천 4종·암페어 루프(모양·중심·크기·방향)·자기 모드 표시 칩·저장 당시 모드(전기|자기)까지 담습니다. 열면 두 모드의 되돌리기 이력을 모두 비우고 저장된 모드로 전환하며, 예전(version 1) 파일은 그대로 열리되 자기 쪽은 빈 상태·전기 모드로 시작합니다. 자기 원천이 하나라도 잘못된 파일은 이유(예: `자기 원천 2(S1): …`)와 함께 통째로 거부합니다(전기 전하와 같은 방식). 전자기 작업에는 자동 저장·공유 링크가 없어 파일 저장·열기만 해당합니다.
- `기본 모델`(접힘): 자유 배치 외에 점전하·쌍극자·직선전류·전류고리·평면파를 값 입력 폼으로 봅니다(평면파는 `재생`·시간 슬라이더). `고급`(접힘): 보는 평면(xy/xz/yz), 예제 8개와 별도 EM JSON 저장/열기(회로 파일과 다름), 발산·회전·선속·순환 미분·적분 프로브.
- **3D**: 같은 상태를 WebGL(외부 라이브러리 없음)로 봅니다. 빈 곳을 끌면 시점 회전, 휠·핀치 확대, `+x/+y/+z/시점 초기화`, 전하는 편집 평면 위에서 끌 수 있습니다. WebGL을 못 쓰면 수치 결과만 나옵니다.
- **문제 풀이**(별도 지연 모듈): 첫 진입 실험은 로런츠 원운동(`force-lorentz`)이고 분야 선택은 `Hayt Ch.8 (6주차)` 묶음이 먼저, `전자기1 복습` 묶음이 그 뒤이며 실험 제목에는 주차 접미(` · 6주차 §8.x`)를 붙이지 않습니다. 44개 실험, 분야 선택 11개. 앞의 23개는 정전계·정전용량·정자계·경계조건·가우스·암페어·자기유도·파동·전송선이고, 뒤의 19개가 **Hayt Ch.8 강의 실험**(6주차)입니다: `자기력·토크`(로런츠 원운동, 직선전류 옆 직사각 루프, 평행 도선·면전류판, 솔레노이드 자기압, 루프 토크 τ=m×B, 쌍극자 원거리장, 두 미분 전류 요소 사이의 힘(교재 예제 8.2: 작용·반작용이 성립하지 않음)) · `자성체·경계`(자화·구속전류, 자화율·투자율, 자기 경계조건·굴절, 철·초전도체 위 선전류의 영상) · `자기회로`(공극 코어의 NI·B — 비선형 B–H 표에서 μ를 갱신하는 반복 풀이, 히스테리시스 루프와 손실의 개념 모형, 3다리 코어의 병렬 자기회로 — 선형 μ_r에서 R = R_c + R_L∥R_R, 자속 Φ·Φ_L·Φ_R과 오른쪽 공극 g₂ 스윕) · `에너지·인덕턴스`(솔레노이드·동축·토로이드 L, 상호 인덕턴스, 가상변위법으로 구한 공극 흡인력·두 솔레노이드 사이의 힘). 로런츠 원운동·히스테리시스는 궤도·루프(xy-곡선)를 그리고 그림을 가로로 끌거나 ←/→로 위상을 옮기며, 영상 전류 실험은 경계면·영상 전류 기호를 그림 위에 덧그립니다(overlay). 로런츠 실험에는 균일 전기장 E_y(+y 방향, 기본 0, ±1×10⁶ V/m)를 숫자로 줄 수 있어 E×B 드리프트 v_d=E/B가 겹치고 E=vB에서 직진합니다(입사 방향은 +x). 한 화면에 그림 + 조건 슬라이더 줄(값을 직접 입력할 수도 있음) + 숫자 답 + 접이식 풀이(문자식)이며, 슬라이더를 움직이면 그림·답·검증이 바로 갱신되고 숫자/문자 보기를 오가도 그림이 유지됩니다. **시간 의존 5개**(패러데이 루프, 운동 기전력, 매질 평면파, 평면 경계 반사, 무손실 전송선)에는 시간 슬라이더와 `재생`이 있고 기전력 ℰ(t) 그래프·순간 파형이 함께 움직입니다. 조건 입력은 **상황에 따라 바뀝니다**(`visibleWhen`): 예를 들어 `자기회로`의 공극 코어는 풀이 방향이 `목표 B → 필요한 NI`이면 B만, `주어진 N·I → B`이면 N·I만 보이고, 코어 재료가 비선형 B–H 표인지 선형 μ_r인지에 따라 B–H 점 또는 μ_r만 보입니다. 각도는 도(°)로 입력하며, 좌표를 훑는 실험(루프 토크 등)은 슬라이더 옆의 **좌표 숫자 입력칸**에 값을 직접 쳐 넣을 수 있고(범위 밖은 `… 범위 밖입니다`를 보이고 마지막 유효 값을 유지) `구할 값` 선택은 `답 / 중간값 / 좌표` 묶음으로 나뉩니다. 수치·기호 정의는 실험별 `evaluate()`가 단독으로 정합니다.

**신호 및 시스템**(수업 Ch.01·02·04) — 수업 레슨 탭 7개와 `참고 ▾` 탭 1개(폰에서는 4×2 격자로 모두 보임; `참고 ▾`를 누르면 레슨 위의 선택 상자로 `Laplace / Z`·`표본화`, 이후 진도 참고 레슨 둘을 고릅니다). 레슨마다 조건 슬라이더 1~3개(폰에서 슬라이더 42px·select 40px, 그림 높이는 화면의 55dvh 이하) + 큰 그림 한 장 + 한 줄 설명(`읽기`) + 접힌 `핵심 수식`이고 드래그·키보드로도 조작합니다. 축·척도·시스템처럼 **고르는 값은 슬라이더가 아니라 select**입니다(값은 선택지 번호). 컨볼루션만 접힌 `고급 입력`(식·수열 직접 입력)이 있습니다. 레슨별 핵심 관찰:

그림에서 연속시간 신호의 점프(예: u(0)이 정의되지 않는 계단)는 양쪽 극한을 **열린 원**으로, 구간 표기로 값이 정해진 쪽은 **채운 원**으로 그립니다.

재생은 학습자가 끌기·키·스크러버로 개입하면 끝나고(파라미터 슬라이더는 재생을 멈추지 않음), 탭이 숨겨지거나 창이 포커스를 잃으면 멈췄다가 돌아오면 이어집니다. `움직임 줄이기` 설정이면 자동 재생이 꺼지고 `재생` 단추를 눌러야 움직입니다.

**회로 과정**(네 번째 탭, 돌아가기 단추는 `← 회로 편집기`; 수업 전기회로2 Ch.9–13): 숫자 실험 5개·`내 문제`·값을 바꾸면 결과가 곧바로 바뀌는 도구 7개(Y–Δ 변환 + 새 도구 6종)를 **교재 장별로 묶어** 두 단계로 고릅니다: 먼저 장(`Ch9–10 페이저·임피던스` · `Ch11 교류 전력` · `Ch12 3상 회로` · `Ch13 자기결합` · `내 문제`), 그다음 그 장의 항목 탭입니다(폰에서는 두 줄). 마지막으로 연 장·항목은 이 브라우저에 기억합니다. 예제 단추는 3개를 넘으면 접혀 있고 요약 줄에 `예제 n개 · 마지막 적용: …`이 보입니다. 머리의 `진폭 표시 기준` 단추 `peak (최댓값)` / `RMS (실효값)`는 **과정 전체**에 적용됩니다. 내부 계산은 항상 RMS이고, 누르면 같은 물리량의 입력 칸·페이저·표가 √2배 값으로(다시 누르면 원래 값으로) 다시 쓰입니다. peak로 적힌 강의 예제를 누르면 기준 단추도 따라 바뀝니다.
- **실험 1–5**(복소수→페이저→파형, R/L/C 복소 회로, 복소전력, 균형 3상, 역률 보상): 처음에는 문자식·법칙·유도(`학습 방식`)로 열리고, `숫자 시현·그래프`로 바꾸면 값을 입력하는 즉시 페이저·시간파형·전력삼각형이 갱신됩니다(적용 단추 숨김). 잘못된 입력은 이유를 상태 줄에 적고 마지막 유효 결과를 그대로 둡니다. 강의 예제 단추는 항상 기본값에서 시작하며(앞선 입력 위에 겹치지 않음), 교재 수치가 있는 예제는 `강의 기대값 대조` 표에 화면에 보이는 결과로 PASS/FAIL을 냅니다(교재의 중간 반올림은 비고에 적음). `내 문제`만 `문제 풀기` 단추가 있으며 문자식 답 → 같은 조건의 수치 풀이로 이어집니다. `내 문제` 유형은 단상 RLC·균형 3상·역률 보상(문자식·숫자 풀이)에 더해 숫자 풀이만 있는 Ch.12–13 세 가지가 있습니다(유형을 고르면 풀이 방식이 숫자로 바뀝니다): `Ch.13 결합 코일 2루프`(V·ω·Z1·ZL·L1·L2·M 또는 k·점 위치 → 메시 방정식 두 줄과 ±jωM 부호 설명, Z22·반사 임피던스·Zin, I1·I2, 소자 전력), `Ch.13 이상 변압기`(n·점·I2 기준 방향·Z1·ZL·Vs → Zin=Z1+ZL/n², I1·I2·V1·V2, 부하 전력과 점 규약 부호 단계), `Ch.12 균형 3상 + 선로 Zℓ`(Y–Y·Y–Δ·Δ 전원, 상전압 또는 선간전압, 선택 선로 Zℓ, abc/acb → 한 상 등가, 선·상전류, P·Q·S, 역률). 입력은 peak/RMS 기준을 고르며, 교재 예제 13.1·13.8·12.3 단추로 열 수 있습니다. 계산은 기존 `coupledCoils`·`idealTransformer`·`solveThreePhase`를 그대로 씁니다.
- **도구 탭 7개**(번호는 탭 이름의 순서): `7 · Y–Δ 변환`(로그 슬라이더·SI 값 입력으로 Y↔Δ, 폰에서는 두 회로를 위아래로 쌓음. `저항 / 복소 임피던스` 선택: 복소 모드는 `3+j4`·`5∠53.13°`·`j10` 같은 입력으로 같은 식을 복소 연산하고, 변환 결과를 직교형·극형으로 보이며 단자 쌍에서 본 임피던스가 Y와 Δ에서 같은지 대조합니다. 분모(Σ 또는 S)가 0이면 이유를 알리고 마지막 결과를 유지. 편집기의 Y–Δ 변환은 저항만) · `8 · 복소수 계산기`(직교형 a+jb·극형 r∠θ°를 섞은 식, `eval` 없이 직접 해석) · `9 · 3상 확장`(전원 Y/Δ·상순서 abc/acb·기준 위상, 선로 임피던스, 부하 Y/Δ·불평형, 중성선 없음/이상/Zn, 그리고 VL·IL·P → 역률 역문제) · `10 · 병렬 부하 합성`(P/Q/S/pf 입력 방식 4가지, S=ΣSk, 목표 역률까지 보상 커패시터, 단상·균형 3상) · `11 · 최대전력전달·AC 테브냉`(ZL=ZTh* 정합과 P(RL)·P(XL) 곡선, 효율) · `12 · 자기결합 코일·T/π 등가`(맨 위 `보기` 단추 셋: `회로 풀이` = 전원·Z1·ZL에서 I1·I2와 반사 임피던스 ZR=ω²M²/Z22, Zin=Z1+jωL1+ZR · `T/π 등가` = L1·L2·M·점만으로 T·π 인덕턴스 · `에너지` = w=½L1i1²+½L2i2²±M i1 i2를 i1·i2 직접 입력 또는 회로 풀이의 시각 t로; 값은 보기끼리 공유하고 그 보기에 필요한 입력·결과만 보이며, 예제를 누르면 해당 보기로 바뀝니다) · `13 · 변압기`(이상·정격·단권·3상 뱅크; 단권은 부하 역률 pf·지상/진상을 넣으면 전도 S_cond와 자기결합 S_ind의 S·P·Q 분배와 공통 권선 전류 |I1−I2|를 보임). 각 도구에 교재 예제 단추가 있어 누르면 값이 채워지고 `강의 기대값 대조`(모두 일치 / 불일치 있음)가 따라옵니다. 도구 값이 틀리면 필드 옆에 이유가 뜨고 결과는 마지막 유효 값에 머뭅니다. 3상 확장의 `전력계 표시` select(평형 부하에서만 보임)를 `2전력계법`으로 하면 W1=V_L·I_L·cos(θ+30°), W2=cos(θ−30°), P=W1+W2, Q=√3(W2−W1)을 보이고(교재 §12.10 규약, pf<0.5에서 W1 음수 안내) 프리셋이 둘 있습니다(`θ=60°, W1≈0`, `pf<0.5, W1 음수`). 예제·프리셋을 적용하면 상태 줄 앞에 `예제 적용: 기준 peak → RMS, … 변경` 요약이 붙고 다음 입력에서 사라집니다.

예제 회로 11개(`파일` 메뉴): 분압기, RC 충전, RC 저역통과(AC), RL, 직렬 RLC, 병렬 RLC SIN/AC, 다이오드 반파 정류, 비반전 OP AMP, Y 저항망(Y–Δ 변환), 결합 코일(예제 13.1), 이상 변압기(예제 13.8).

## 조작표

### 회로 편집기

회로 편집기에서 글자를 입력하는 칸(텍스트·숫자 입력, 문자열 칸)에 포커스가 없을 때입니다. 체크박스·버튼·슬라이더가 포커스를 쥐고 있어도 동작하며(슬라이더·목록은 방향키만 자기 것), 캔버스의 부품을 누르면 그런 포커스는 풀립니다. macOS는 `Ctrl` 대신 `Cmd`도 됩니다.

| 키 | 동작 |
|---|---|
| `R` / `Shift+R` | 선택 부품 시계 / 반시계 회전 (여러 개면 기준 부품을 축으로 함께) |
| `Delete` / `Backspace` | 선택 항목 전체 삭제 (입력 칸에 글자를 쓰는 중에는 동작하지 않음) |
| `Ctrl+D` | 선택 부품 복제 (제어원은 복제 버튼 Shift+클릭 = 제어 대상까지). 여러 개면 사이 배선도 함께 |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 복사 / 잘라내기 / 붙여넣기 (붙여넣을 때마다 2칸 비껴 놓이고 붙여넣은 항목이 선택됨) |
| `Ctrl+A` | 모두 선택 |
| `Shift`+클릭 / `Shift`+빈 곳 끌기 | 선택에 더하기·빼기 / 상자 선택 |
| `Ctrl+Z` / `Ctrl+Y` 또는 `Ctrl+Shift+Z` | 되돌리기 / 다시 하기 |
| `W` / `V` | 배선 도구 / 선택 도구 |
| `Y` | 선택한 저항 3개의 Y↔Δ 변환 (Y 또는 Δ로 인식될 때만) |
| `←` `↑` `↓` `→` (`Shift` = 5칸) | 선택한 부품·접속점 전체를 격자 단위로 이동. 캔버스·도구 버튼에 포커스가 있을 때만. 누르고 있어도 undo 한 단계 |
| `Esc` | 한 단계씩 물러남: 메뉴·인라인 편집 → 끌던 배선·상자 → 그리던 배선 → 도구 → 선택 해제. 파형 그래프에 포커스가 있으면 커서 A·B만 풀립니다 |
| `Ctrl+S` | JSON 저장 (입력 칸에서도 동작) |
| `Ctrl+Enter` | 해석 실행 (입력 칸에서도 동작: 입력 중인 값을 먼저 확정한 뒤 실행) |

마우스·터치: 항목 클릭 선택(`Shift`+클릭 다중 선택), 선택 항목 끌기 이동, 빈 곳 끌기 화면 이동(`Shift`+끌기 = 상자 선택), 핀에서 끌어 배선, 캔버스 휠 확대·축소. 터치는 먼저 탭해서 선택한 부품만 끌어 이동하고, 그 밖의 한 손가락 끌기는 화면 이동(배선 도구에서는 핀에서 끌면 배선), 두 손가락은 확대·축소입니다. 탭 목록(작업공간·패널)은 `←` `→` `Home` `End`로 이동합니다. 캔버스의 `조작 도움말`에 같은 내용이 요약돼 있습니다.

### 파형 그래프

파형 그래프(클릭하거나 `Tab`으로 포커스)에서:

| 입력 | 동작 |
|---|---|
| `←` `→` / `Home` `End` | 커서 A를 한 표본 / 처음·끝으로 (고정됨) |
| `Shift` + 위 키 | 커서 B 이동 |
| `Esc` | A 고정 해제, 다시 누르면 B 지움 |
| 클릭 / `Shift`+클릭 | A 고정 / B 놓기 |
| 끌기 | 시간·주파수축 이동 |
| 휠 / `Shift`+휠 (또는 왼쪽 축) / `Alt`+휠 (또는 오른쪽 축) | 가로축 / 첫째 Y축 / 둘째 Y축 눈금 |

### 전자기학 평면

캔버스에 포커스가 있을 때(누르거나 `Tab`):

| 입력 | 동작 |
|---|---|
| `[` / `]` | 이전 / 다음 전하 선택(처음과 끝은 이어짐). 선택은 화면 낭독기에 알립니다 |
| `Tab` / `Shift+Tab` | 전하를 차례로 선택하되 처음·끝을 넘으면 포커스가 캔버스 밖으로 나감(키보드 함정 없음) |
| `←` `↑` `↓` `→` (`Shift` = 5배) | 선택한 전하를 0.05 m씩 이동(전하가 없으면 시험전하 이동). 한 번이 되돌리기 한 단계 |
| `Delete` | 선택한 전하 삭제(자유 배치일 때) |
| `Esc` | 끌던 전하를 원래 자리로 되돌리고 끌기 취소 |
| 휠 / 끌기 | 커서 기준 확대·축소 / 전하·시험전하·가우스 면 이동 |

자기 모드에서는 같은 키가 전류 원천(도선·루프·면전류·유한선)에 적용됩니다. 3D 캔버스에서는 방향키가 시점을 돌리고 `+` `−`가 확대·축소, `Home`이 시점 초기화입니다. 문제 풀이 화면과 신호 화면의 슬라이더·`재생` 단추는 일반 컨트롤처럼 `Tab`·방향키로 씁니다.

### 신호 및 시스템

그림이 있는 레슨(시간축·LTI 응답의 계단응답 예시·컨볼루션·푸리에 급수·Laplace/Z)에서 그림에 포커스가 있을 때(누르거나 `Tab`):

| 입력 | 동작 |
|---|---|
| `←` `→` | 관측 위치(시각 t, 점 τ, 이산은 정수 n)를 한 칸 이동. `Shift` = 10칸 |
| `Home` `End` | 관측 범위의 처음 / 끝 |
| `Space` | 재생 / 일시정지(컨볼루션·푸리에 급수) |
| (Laplace/Z) `←` `→` `↑` `↓`, `Shift` = 큰 걸음 | 극점 이동. 양측 신호는 `Space`·`Enter`로 움직일 극점을 바꿉니다 |

그림 끌기·스크러버·키 입력은 재생을 멈추고 직접 조작으로 넘기며, 신호 연산·푸리에 변환·주파수 응답·표본화 레슨은 슬라이더·select로만 조작합니다. 터치는 끌 수 있는 손잡이 위에서 시작한 한 손가락만 제스처로 받고 그 밖에서는 페이지가 스크롤됩니다. 끌 수 있는 그림(시간축·LTI·컨볼루션·급수·푸리에·주파수 응답·ROC)은 폰(700px 이하)에서만 그림 아래에 한 줄 힌트(`● … 끌어 이동`)를 보이고 데스크톱에서는 숨깁니다. 주파수 응답은 이제 포커스되는 그림(탭 정지점)입니다.

## 저장·복원·공유

- **JSON 저장/열기**: `저장`(또는 `Ctrl+S`)은 회로·해석 설정·프로브를 `circuit-lab` JSON 파일로 내려받습니다(소자에 따라 version 1~4, 결합 인덕터·이상 변압기가 있으면 4). `열기`는 구조와 해석 가능성을 따로 검증하며 잘못된 파일은 이유와 함께 거부합니다(4,000,000자 이내). 테마는 회로와 분리돼 있습니다. 전자기학 탭은 자체 JSON(`EM 파일 저장`, 자기 모드 포함)을 씁니다.
- **자동 저장**: 편집이 확정되면 0.8초 뒤 브라우저 `localStorage`에 저장합니다. **탭마다 자기 슬롯**(`circuit-lab.autosave.v2.<탭 id>`, 탭 id는 `sessionStorage`)에만 쓰므로 다른 탭 작업을 덮어쓰지 않으며, 슬롯은 최대 5개(가장 오래된 것부터 삭제)입니다. 새 회로·열기·예제·링크·복원처럼 프로젝트를 통째로 바꿀 때는 바꾸기 직전 마지막 편집까지 먼저 저장하고, 그 슬롯을 탭마다 하나뿐인 `<탭 id>.prev`로 옮긴 뒤 새 프로젝트를 저장하므로 다음 편집이 이전 작업을 덮어쓰지 않습니다(5개 한도에는 둘 다 셉니다). 빈 캔버스나 편집 도중 유효하지 않은 상태는 저장하지 않고 이전 저장본을 보존합니다. 저장소를 못 쓰면(사생활 모드·용량 초과) 상태 표시줄에 알립니다 — 중요한 작업은 JSON으로 저장하십시오.
- **복원 배너**: 시작할 때 현재 회로와 다른 가장 최근 슬롯(이 탭의 슬롯·prev·다른 탭 것)이 있으면 캔버스 위에 `이전 작업이 있습니다 (N분 전)`와 `복원`/`무시`가 뜹니다. 자동으로 적용되지 않으며, 복원은 undo 한 단계입니다. 새 회로·시작 시 `?example=`·공유 링크는 다음 실제 편집 전까지는 이전 자동 저장을 덮어쓰지 않고, 복원은 복원한 내용을 곧바로 저장하되 그때 화면에 있던 작업은 prev 슬롯에 남깁니다.
- **링크 공유**: `파일 > 링크 복사`는 현재 회로·설정·프로브를 주소의 `#p=` 해시에 담아 복사합니다(서버로 보내지 않음). 압축 가능하면 `z.`(deflate-raw+base64url), 아니면 `j.`(JSON) 형식입니다. **한계: 압축 전 JSON 200 KiB, 전체 주소 8000자**를 넘으면 `너무 커서 링크로 공유할 수 없습니다`가 뜨니 파일로 저장하십시오. 링크를 열면 같은 파서로 검증한 뒤 시작 회로를 대체하며(우선순위: 공유 링크 > `?example` > 복원 배너), 열 수 없으면 이유를 알리고 기본 편집기를 유지합니다. 열린 탭의 주소 창에 `#p=` 링크를 붙여 넣어도(해시 변경) 같은 방식으로 열립니다(입력 중인 값이 있으면 먼저 확인, 이전 작업은 prev 슬롯에 보존, 되돌리기 한 단계). 첫 편집 뒤에는 주소의 시작 매개변수를 지웁니다.

## 시험

```powershell
npm test               # 엔진 + UI 모델 + 도구 시험 (1615개: 마지막 실측, 정확한 수는 출력으로 확인, 약 6초, Node >=22)
npm run check          # src 경계 검사 (import 사이클·순수 모델의 DOM 의존 등)
npm run test:browser   # 헤드리스 Edge 종단 스모크 (139개 시나리오: 마지막 실측, 약 3분: 회로 편집·해석·저장·공유 + 전자기·신호·회로 과정 작업공간)
npm run test:all       # test + test:browser
npm run test:summary   # npm test와 같은 범위, 요약 출력 + 원시 TAP를 .verification/ 에 보관 (engine|ui-model|all, --out <폴더>)
```

브라우저 스모크는 `node server.mjs 0`과 임시 프로필의 헤드리스 Edge를 직접 띄웁니다(npm 패키지 없음, Node 22의 전역 `WebSocket` 사용). Edge가 없으면 건너뛰지 않고 실패하며 `EDGE_PATH`로 경로를 지정합니다. `CIRCUIT_LAB_ROOT`로 다른 체크아웃을 시험할 수 있습니다. 구조는 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)의 "시험 구조"를 보십시오.

## 브라우저·환경

- 확인 대상은 Chromium 계열(Edge/Chrome)입니다. ES 모듈, module Worker, `inert`, SVG, `ResizeObserver`가 필요합니다. Firefox·Safari·실제 모바일 기기의 손가락 입력은 확인하지 않았습니다(390px 폭 경로만 시험).
- `CompressionStream`/`DecompressionStream`이 없는 브라우저는 압축 없는 `j.` 링크를 만들고, 압축 링크(`z.`)는 열 수 없다는 안내를 보입니다.
- 클립보드 API가 막히면 링크를 선택 가능한 칸으로 보여 줍니다. WebGL을 못 쓰면 전자기학 3D는 수치 결과만 제공합니다.
- 서버는 같은 PC의 `127.0.0.1`만 받으므로 휴대폰에서 직접 열 수 없습니다.

## 범위

- 해석은 교육용 저차 모델입니다. 다이오드는 간략 Shockley, OP AMP는 유한 이득 또는 `V+=V−` 제약이며 rail·포화·GBW·slew가 없습니다. 실제형 OP AMP, AC/소신호 포트, 재료를 포함한 전자기 해석은 없습니다. 전자기학 평면은 점·선전하와 내장 모델만 다루고, 신호 레슨은 지원하는 신호 족(식 직접 입력은 컨볼루션만, 제한 산술식)이며 일반 기호 대수 엔진이 아닙니다. 터치에는 다중 선택(상자·Shift)이 없습니다.
- 값은 `E/e`, `µ/μ/u`, `M`/`meg`/`m` 접두사를 읽지만 물리 단위 차원 검사는 하지 않습니다.
