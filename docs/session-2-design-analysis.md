# 세션 2 — 실험 설계 및 해석 인계

## 반드시 보존할 수치 계약
표시 배율 변경 전후의 `result`와 CSV 원시 수치가 같아야 한다. 자동 설정은 시작 범위의 휴리스틱이지 회로의 정확한 pole 계산이 아니다. SIN과 AC는 독립된 자극이고 IC는 사용자가 지정한 초기 상태다.

## 독립 판정 예
| 실험 | 조건 | 기대 |
|---|---|---|
| 병렬 C 방전 초기점 | C1=1µF, C2=3µF, 각 IC=5V, R=1kΩ | V=5V, I_R=5mA, I_C1=-1.25mA, I_C2=-3.75mA |
| C 삼각망 초기점 | C_A0=1µF/3V, C_B0=2µF/1V, C_AB=3µF/2V, R_A=1kΩ, R_B=2kΩ | dV_A/dt=-1500V/s, dV_B/dt=-1000V/s; 각 노드 KCL=0 |
| SIN 병렬 C 초기점 | offset5V, amplitude2V, f1kHz, phase0, C1µF, IC5V | I_C(0)=C·2·2π·1000≈12.56637mA |
| 오실로스코프 배율 | RC 파형의 V/div, A/div, s/div 변경 | 물리 표본·CSV 불변, 1–2–5 배율, 고정/자동 표시 |
| 커서 | 첫 X 표본 위치 | index0, time0; SVG 여백을 포함한 전체 폭 비례식 금지 |
| 실행 실패 | banana, 모순 IC, 지원 밖 | 오래된 결과를 현재 성공으로 표시하지 않음 |

각 시험의 식과 기대값은 구현 함수에서 다시 계산해 가져오는 방식으로만 만들지 않는다. KCL/전력·에너지 및 dt 절반 수렴으로 독립성을 보강한다. 이번 Node 시험은 기존 70개와 추가 30개이며 모든 회로를 포괄한다는 뜻은 아니다.

## 추가 설계가 필요한 것
자동 해석 추천이 RC/LR 극단 조합에서 놓치는 빠른 시간척도, 독립 전압원과 커패시터 제약의 반복/반대 극성/전원 불연속, 부유 common-mode, OPAMP 초기 미분계, AC 0크기 위상, 절대 pivot 임계값/조건수 문제를 별도 실험으로 정의한다. 현재 backward Euler의 수치 감쇠를 이상 소자의 물리적 감쇠라고 설명하지 않는다.

## 화면 승인
1024와 모바일에서 회로/결과 전환을 사용한 것은 의도된 설계다. 두 패널을 동시에 유지해야 한다는 요구가 생기면 따로 검토한다. 아주 작은 같은 단위 신호를 개별 정규화해 크게 보이는 것과 물리적 공통 축의 관계를 구분한다.
