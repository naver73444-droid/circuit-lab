# VCVS / VCCS

두 종속원은 pin 1/2/3/4를 각각 `p`, `n`, `cp`, `cn`으로 사용합니다. 출력 전압과 전류의 양의 방향은 `p→n`, 제어 전압은 `V(cp)-V(cn)`입니다. 제어 핀은 전류를 소비하지 않으며 출력 회로와 전기적으로 단락되지 않습니다.

- VCVS: `V(p)-V(n) = g·(V(cp)-V(cn))`. `g`는 무차원이며 기본값은 1입니다.
- VCCS: `I(p→n) = gm·(V(cp)-V(cn))`. `gm`의 단위는 S이며 기본값은 1 mS입니다.

`g`와 `gm`은 0 및 음수를 허용합니다. `g`에는 숫자와 SI 접두어만, `gm`에는 단위 생략 SI 또는 S/mS/µS를 사용합니다. 소문자 `s`는 시간 단위와 혼동되므로 gm에서 허용하지 않습니다.

새 종속원을 포함한 회로·프로젝트는 version 2 JSON으로 저장됩니다. 기존 부품만 있는 파일은 version 1을 유지하며 후보는 두 버전을 모두 읽습니다. VCVS/VCCS를 version 1로 위장한 파일, 잘못된 핀과 probe 참조, 유효하지 않은 계수는 명시적으로 거부합니다.

DC, 같은 시각의 transient, 복소 AC에서 동일 MNA 관계를 사용합니다. CCCS/CCVS, 실제형 종속원, rail·포화·대역폭, 센서/포트 모델은 포함하지 않습니다. VCVS 출력과 중복 커패시터 IC의 초기 미분 전류가 하나로 정해지지 않는 회로는 기존 명시 미지원 경계를 따릅니다.
