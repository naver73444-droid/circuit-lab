# 세션 1 — 프로젝트 운영관리 인계

## 현재 상태
CIRCUIT-007 원본에서 파생한 UX 검토 후보. 사용자 PC에는 미적용. `REVIEW-007-UX.md`와 evidence 로그를 기준으로 통합한다. 모든 변경을 한 번에 확정 릴리스로 취급하지 않는다.

## 통합 순서
1. 별도 브랜치/복사본에서 원본 보존과 기준 SHA-256 확인.
2. 입력 확정·실행 세대·삭제 참조·JSON 검증을 먼저 검토.
3. 순수 scope 모델, 화면 렌더러, 휠 UI, 간소화된 해석 흐름을 통합.
4. 병렬 C 초기 전압/전류 수정은 수치 담당 세션의 독립 검토 후 승인. OP AMP와 중복 C 초기제약 조합은 여전히 지원 제한이 있다.
5. exporter 복원/검증 제한 변경과 source payload 목록을 확인.
6. Windows 실제 localhost 실행, 고해상도/배율/터치 시험 후 채택 여부 결정.

## 다음 작업 배정

| UX-LOCAL | 실행 | Windows Node 서버+Chromium/Edge 실제 HTTP | 22개 브라우저 시나리오 통과, 확대 배율 100/125/150% 점검 |

| CORE-SPLIT | 실행 | app의 edit/run controller 분리 | 행동 동일, 상태 소유자 명확, 성급한 프레임워크 전환 금지 |

## 승인 규칙
시험 기대값의 소유자는 설계 세션, 구현 증거의 소유자는 실행 세션, 최종 통합 승인은 운영관리 세션이다. 한 세션이 기대값을 변경하고 자기 구현을 혼자 승인하지 않는다. 실패한 시험을 삭제해 통과 수를 맞추지 않는다.

## 인계 최소 형식
`기준 버전 / 실험 ID / 변경 파일 / 독립 기대값 / 실행 명령 / 결과 / 미검증 / 다음 담당`. 외부 Skill 설치는 프로젝트 코드 통합과 별도 승인 항목이다.
