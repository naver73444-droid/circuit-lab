# 회로도 사진 → 회로 편집기 (넷리스트 붙여넣기)

실험 지침서·슬라이드의 회로도를 사진으로 찍어 회로 편집기에 옮기는 방법입니다. 사진을 읽는 일은 Claude 앱이 하고, 편집기는 Claude가 써 준 **넷리스트 글**을 받아 부품을 놓고 배선합니다. 사진은 앱이나 사이트로 올라가지 않습니다.

## 순서 (아이패드·폰)

1. 편집기 `파일 → 넷리스트 붙여넣기`를 열고 **Claude 안내문 복사**를 누릅니다(처음 한 번이면 됩니다. Claude 프로젝트를 쓰면 프로젝트 지침에 넣어 두세요).
2. Claude 앱에 회로도 사진을 올리고 복사한 안내문을 붙여 보냅니다.
3. Claude가 준 코드 블록을 길게 눌러 복사하고, 편집기의 같은 창에 붙여 넣습니다.
4. 창 아래에 읽은 부품이 한 줄씩 보입니다(값은 단위까지 풀어서). 사진과 다르면 그 줄을 고칩니다. 읽을 수 없는 줄은 빨간 글자로 몇째 줄인지와 이유가 나오고 `불러오기`가 꺼집니다.
5. `불러오기` → 회로가 놓이고 해석 설정·프로브가 함께 들어옵니다. `해석 실행`으로 계산합니다. 되돌리기 한 번이면 이전 회로로 돌아갑니다.

## 읽는 글 (SPICE의 일부)

```
* RC 1차 회로 (실험 1-1)              ← 첫 '*' 줄은 회로 이름, 다음 '*' 줄들은 설명
* 신호 5Vpp 1kHz 구형파, C는 11nF와 47nF 각각
V1 in 0 PULSE(-2.5 2.5 0 1u 1u 0.5m 1m)
R1 in out 1.5k
C1 out 0 11n
.tran 5u 3m
.probe V(in) V(out)
```

- 부품: `R C L`(값), `V I`(전원: `DC 5`, `SIN(오프셋 진폭 주파수)`, `PULSE(V1 V2 지연 상승 하강 폭 주기)`, 뒤에 `AC 크기 [위상]`), `D`(애노드 캐소드), `U`(이상 OP AMP: +입력 −입력 출력). 접지는 `0`.
- 단위 접두사 `k meg m u n p`. **대문자 `M`은 받지 않습니다**(SPICE에서는 밀리, 다른 곳에서는 메가라 헷갈림). 값 뒤 `Ω F H`는 있어도 됩니다.
- `.tran 간격 끝`, `.ac dec 점수 시작 끝`, `.probe V(노드) I(부품)`. `.tran`이 없으면 주기 전원은 세 주기 시간응답, 아니면 DC입니다. `.probe`가 없으면 전원 노드와 마지막 노드의 전압을 잽니다.
- 트랜지스터·스위치·종속 전원·결합 인덕터는 아직 읽지 않습니다(줄 번호와 함께 알려 줌). 결합 인덕터·변압기·종속 전원은 편집기에서 직접 그리면 됩니다.

## 배치 규칙

전원은 왼쪽에 + 위로 세웁니다. 노드는 전원에서 부품을 따라 닿는 순서대로 왼쪽→오른쪽에 놓고, 노드와 접지 사이 부품은 그 노드 아래에 세로로, 두 노드 사이 부품은 위쪽 줄에 가로로(병렬·건너뛰는 부품은 그 위 줄) 놓습니다. OP AMP는 아래 줄입니다. 접지된 핀마다 접지 기호를 하나씩 핀 방향으로 붙이고(지침서 그림처럼), 배선은 `배선 정리`와 같은 자동 직교 경로입니다. 놓인 부품은 끌어서 옮기면 배선이 따라옵니다.

## Claude 안내문 (편집기의 `Claude 안내문 복사`와 같은 글)

```
회로도 사진을 받으면 Circuit Lab에 붙여 넣을 넷리스트로 바꿔 주세요. 규칙:
1. 코드 블록 하나에 회로 하나. 첫 줄은 '* 회로 이름', 둘째 줄부터 '* '로 사진에 적힌 실험 조건(신호, 바꿔 끼우는 값 등).
2. 부품 줄: 이름 노드… 값. 접지는 0, 다른 노드는 in, out, n1처럼 짧은 영문.
   R1 in out 1.5k / C1 out 0 11n / L1 a b 10m / D1 애노드 캐소드 / U1 +입력 −입력 출력 (이상 OP AMP)
3. 단위 접두사: k, meg, m, u, n, p (대문자 M은 쓰지 말 것). 값 뒤 단위 글자(Ω F H)는 생략.
4. 함수 발생기 전원: 정현파 Vpp는 진폭 = Vpp/2 → V1 in 0 SIN(0 2.5 1k). 구형파 ±Vpp/2 → V1 in 0 PULSE(-2.5 2.5 0 1u 1u 0.5m 1m) (폭 = 주기/2). 직류는 V1 in 0 DC 5.
5. 해석: 시간 파형은 '.tran 간격 끝시간' (주기의 3~5배, 간격은 주기/200), 주파수 응답은 '.ac dec 50 시작 끝'. 측정할 값은 '.probe V(노드) I(부품)'.
6. 값이 여러 개(예: C 11nF, 47nF)면 첫 값으로 쓰고 나머지는 '*' 줄에 적기. 사진에서 확실하지 않은 부분은 코드 블록 밖에 한 줄로 알려 주기.
7. 트랜지스터·스위치처럼 R C L V I D U가 아닌 부품은 넣지 말고 블록 밖에 따로 적기.
```
