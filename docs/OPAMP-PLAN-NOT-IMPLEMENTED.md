# OP AMP 계획 — 미구현

이번 검토에서도 아래 두 모델은 구현하지 않았습니다. 아래는 업로드 인계 문서의 7절을 보존한 내용입니다. 새 성능·기본값·단자 계약을 임의로 확정하지 않습니다. 기존 N1~N5 시험과 OPAMP 지원 제한은 유지합니다.

## 7. OP AMP: 현재 모델과 요청한 두 모델

### 현재 구현

기존과 UX 후보의 OPAMP는 입력 전류0, 출력저항0, 기본 유한 개방루프 이득100000이며 Vout=A(Vplus−Vminus)인 간략 종속전압원이다. 전원핀/출력 포화/대역폭/slew rate가 없다. 완전 이상형도 실제 제품 모델도 아니다. 중복 C 초기미분계와 OPAMP 조합은 지원불가로 명시 중단한다.

### 사용자 요청: 이상형·실제형을 구분해 추가 (미구현)

| 항목 | 이상 OP AMP 계획 | 실제형 OP AMP 계획 |
|---|---|---|
| 목적 | 교과서의 이상 증폭기 비교 | 비이상 특성을 학습하는 설정형 근사 |
| 이득 | 무한 이득의 제약식으로 처리; 임의 큰 숫자 대체와 구분 | 유한 DC 개방루프 이득 |
| 입력·출력 | 입력전류0/출력저항0 | 입력저항·출력저항 포함 범위는 설계 때 명시 |
| 한계 | 포화·속도·대역폭 없음 | 전원 레일 포화·대역폭·slew rate를 목표로 함 |
| 이름·안내 | '이상 OP AMP' | '실제형 OP AMP(교육용 근사)' |
| 현재 상태 | 설계 계약 전 | 설계 계약 전, 특정 제조사 부품 재현 아님 |

이상형의 Vplus=Vminus는 해가 존재하는 선형 폐루프 조건에서 적용하는 제약이다. 양의 피드백/개방루프/모순 회로에서도 무조건 정상 계산된다고 설명하지 않는다. singular·해 없음·비유일 해는 명시 오류/지원 한계로 다룬다.

실제형은 DC 포화, AC의 동작점 주변 소신호 선형화, 시간응답의 대역폭·slew 제한을 일관되게 설계해야 한다. 출력만 사후 clip하고 내부 상태·KCL이 맞는 것처럼 보여서는 안 된다. 전원핀을 추가할지 속성으로 레일을 설정할지, 포화 회복·offset·bias·전류 제한·noise 등 포함/제외 항목과 기본값은 아직 미정이다. 실제 제품 이름이나 정밀 SPICE 대체를 주장하지 않는다.

### OP AMP 별도 작업의 권장 순서

1. 기존 OPAMP 저장 파일/예제를 원래 유한이득 모델로 그대로 읽는 호환 정책, 신규 두 타입과 UI 이름을 정한다. 기존 회로를 몰래 이상형으로 변환하지 않는다.
2. 이상형: follower/반전/비반전/합산 회로의 독립 식·KCL·부하 변경·실패 반례를 계약으로 고정한다.
3. 실제형: DC 이득 및 rail 포화 → 단일극 AC 응답 → transient 대역폭·slew 제한 순으로 나눠 구현·검증한다. 기본값은 설계 때 고정한다.
4. 유한이득 폐루프 A/(1+Aβ), 정해진 극점의 AC 이득/위상, step 응답 및 |dVout/dt| 한계, dt 수렴, rail 경계·재실행 상태를 독립 기준과 대조한다.
5. 동일 회로에 두 모델을 바꿔 넣어 파형·오차·모델 한계를 설명하는 예제를 만든다. JSON 재열기/CSV/단자 전류/기존 회귀를 확인한다.

이번 ZIP 정리는 OP AMP 구현을 시작하거나 008 통합을 승인하는 행위가 아니다. OP AMP 추가 요청은 유효한 다음 작업으로 남아 있으며 별도 작업 카드·설계 계약·실행 전달이 필요하다.
