# DC 테브난·노턴 포트

결과 영역의 **DC 테브난·노턴 포트**에서 p와 n을 차례로 선택하고, 원망에서 제외할 외부 부하를 회로에서 선택해 등록한 뒤 실행한다. 포트 선택은 저장 JSON이 아닌 현재 편집 세션 상태이며 회로를 수정하면 이전 결과는 오래된 결과로 표시된다.

- 전압은 `V=Vp−Vn`, `I_into`는 p에서 원망으로 들어가는 방향이다. 따라서 `V=Vth+Rth·I_into=Vth−Rth·I_load`다.
- Norton 내부원은 n→p, 외부 단락전류는 p→n이다.
- 독립원의 DC 여기만 0으로 바꾸어 Rth를 구한다. SIN/PULSE, AC, IC, 영구 ID, 센서와 종속원 제어 branch는 사본에 그대로 둔다.
- 분석은 사본에서만 수행하므로 원 회로, 배선, 프로브, undo/redo 이력과 저장 데이터는 바뀌지 않는다.
- 이상 전압원형의 Rth 0, 검증된 이상 전류원형의 Rth ∞와 미정 Vth를 숫자 0이나 임의 큰 값으로 바꾸지 않는다.
- 다이오드 전역 등가, AC/동작점 소신호, 제거 부하가 제어 branch인 경우, 내부 이상 branch 비유일은 지원하지 않으며 이유를 표시한다.
