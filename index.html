조작 도움말
회로 편집 조작마우스·터치·키보드 동작을 한곳에서 확인하세요.

선택·이동

  • 마우스: 항목을 눌러 선택하고 끌어 이동합니다. 빈 캔버스를 끌면 화면이 이동합니다.
  • 터치: 먼저 탭해 선택한 항목만 다시 끌어 이동합니다. 그 밖의 한 손가락 끌기는 화면 이동, 두 손가락은 확대·축소입니다.
  • 키보드: R 회전 · Delete 삭제 · Ctrl/⌘+D 복제 · Ctrl/⌘+Z 실행 취소 · Ctrl/⌘+Y 다시 실행

배선·값

  • 배선: 배선 도구에서 핀·접속점을 누르고, 빈 격자점을 눌러 꺾임을 고정한 뒤 다른 핀·배선·접속점에서 끝냅니다.
  • 값 편집: 부품의 값 글자를 두 번 누릅니다. Enter로 적용하고 Esc로 취소합니다.
  • Esc는 진행 중인 배선이나 도구를 끝내고 선택 도구로 돌아갑니다.

프로브·그래프

  • 전압: 핀·배선·접속점을 누릅니다. 전류: 부품을 누릅니다. 프로브 우클릭 메뉴나 목록의 제거 버튼으로 해당 프로브만 지웁니다.
  • 그래프를 누르면 커서를 고정하고, 좌우 방향키·Home·End로 표본을 이동합니다. 휠은 시간·주파수, Shift+휠은 왼쪽 축, Alt+휠은 오른쪽 축 배율을 바꿉니다.

패널·입력

  • 패널의 손잡이를 끌어 위치나 크기를 바꾸고, 배치 메뉴와 작업 공간 막대에서 다시 열 수 있습니다. 구분선은 방향키로 조절하고 Home으로 초기화합니다.
  • 입력 칸을 편집하는 동안 회전·삭제 같은 회로 단축키는 작동하지 않습니다.

왜 이렇게 계산하나요?

극형→직교형: a=X cos φ, b=X sin φ (입력 위상은 도 단위). 형식을 바꿀 때 기존 입력 숫자는 자동 변환하지 않으므로 새 형식에 맞춰 다시 입력하세요.

크기 = √(a²+b²), 위상 = atan2(b,a). atan(b/a)만 쓰면 사분면을 놓칠 수 있습니다.

A+B는 실수끼리·허수끼리 더합니다. 곱셈은 크기의 곱과 위상의 합, 나눗셈은 크기의 비와 위상의 차입니다. j²=−1입니다.

X∠φ가 peak·cos 기준이면 x(t)=X cos(2πft+φ), RMS는 X/√2입니다. 크기 0의 위상과 0으로 나누기는 정의하지 않습니다.

점전하와 무한선은 1 mm, 고리는 max(1 mm, 0.02R) 안쪽을 모델 제외영역으로 둡니다. 화살표와 색은 보기용 정규화이며 세기를 바꾸지 않습니다. 장선은 방향 적분으로 제외영역·영점·장면 경계·최대 step에서 끝납니다.
